# 変更履歴

Tatamiの主な変更点です。このファイルをウェブサイトとGitHub Releasesのリリースノートの基準とし、公開時にインストール・更新案内を追加します。Sparkleの更新画面は同じマイナーバージョンの全パッチをまとめるため、各節にはそのバージョンの変更だけを記載します。

<a id="1140-2026-09-09"></a>
## 1.14.0 (2026-09-09)

ワークスペース切り替えとウインドウ操作の応答性を改善し、保存済みの設定に影響する変更を実行前に確認できるようにしました。

<a id="new"></a>
### 新機能
- **適用前に変更を確認:** アプリの所属・配置変更、削除、設定の上書き、ガイド付き設定の置き換えを実行前に確認できます。確認は操作ごとに独立して有効です。「次回から確認しない」は確定した操作だけに適用され、キャンセルでは設定を維持します。アプリの所属・配置変更では、確定後に同じ HUD で結果を表示します。

<a id="improvements"></a>
### 改善
- **ワークスペース切り替えと入力の応答性を改善:** 設定と配置の書き込みを入力に影響する経路の外で直列化し、重複するポインタ更新をまとめます。ウインドウやフォーカス対象が変わった場合は古い処理結果を破棄します。
- **アプリの動作を一か所で調整:** アプリ行から自動起動と配置方法を直接変更でき、隣のメニューから削除できます。ワークスペースのアプリと共有アプリで同じ操作を使えます。チェーンがないワークスペース行も中央揃えを保ちます。
- **目的別に設定を探す:** カテゴリのサイドバーで、一般、タイル配置、ワークスペース、ワークスペースキー、フォーカスとマウス、ジェスチャー、外観、フックを分けて表示します。確認設定も対象の操作別にまとめました。
- **5言語で使い方を読む・見る:** アプリ内ドキュメントを選択した言語で表示し、見出し、表、リンクが正しく動作します。ウェブサイトには一連の作業フローと機能別デモを用意し、標準の再生操作、キーボード操作、関連設定へのリンクを提供します。

<a id="fixes"></a>
### 修正
- **最前面表示のウインドウに最初のクリック・ドラッグを届ける:** アクティブ化とミラーの引き継ぎ中も最初のマウス入力を保持します。キーボードフォーカスを移さずに背後の実ウインドウをスクロールでき、ホバーは Focus Follows Mouse の設定に従います。
- **ウインドウが一時的に利用できなくても配置を保持:** 配置の読み込みに失敗したり不完全だったりしても、保存済み位置を空の配置で置き換えません。ワークスペースの復元は、必要なウインドウを解決できるまで有効な配置情報を保持します。
- **変更のないワークスペースのコピーを省く:** 一致するコピー元は「違いはありません」と表示され、選択できません。レビューを開く直前にコピー元とコピー先を再確認するため、古いメニューから空のコピーシートを開くことはありません。

<a id="compatibility"></a>
### 互換性
- **自動化の確認設定を見直す:** 既存の設定は新しい操作別の確認がすべて有効な状態で読み込まれます。アプリの所属・配置を保存する CLI コマンドもこの確認を使います。無人実行のスクリプトでは「設定」→「一般」→「変更前の確認」または `[settings.confirmations]` で関連項目を設定してください。ダウングレード前に `config.toml` をバックアップしてください。旧バージョンは保存時に新しい確認項目を保持しません。

<a id="1130-2026-09-03"></a>
## 1.13.0 (2026-09-03)

<a id="new-1"></a>
### 新機能
- **画面をまたぐワークスペース群を復元:** プロファイル設定で順序付きチェーンを作り、いずれかへ切り替えると現在の画面構成に合う仲間も復元します。選んだ領域がフォーカスを保ち、接続済みの固定メンバーが指定画面を使います。動的メンバーは優先順に次の空き画面を使い、残りは既存ルールで補います。サイドバーに関係を示し、変更した各画面に結果を表示します。
- **常駐するフローティング操作部を維持:** 既存のApp選択からNotionなどを登録できます。登録したAppの高いレイヤーの操作部が画面上にある間はプロセスを隠さず、ワークスペースを切り替えても表示を保ちます。通常のウインドウはフォーカス、タイル表示、切り替え、ドラッグ、所属変更の対象外ですが、Mission Controlには表示される場合があります。
- **操作フィードバックを外部へ共有:** 新しい `hud` フックが、通知の翻訳済みタイトル、記号、副題、完全表示時間、位置、サイズ、確定した画面を送ります。SketchyBarなどでログを解析せず同じ情報を表示でき、フック失敗の通知は再帰的に再送しません。

<a id="improvements-1"></a>
### 改善
- **操作フィードバックの位置と大きさ:** 対象画面の辺、角、中央と、小・標準・大を選べます。表示と終了にスプリング動作を使い、設定した時間は完全に見えている区間だけを数えます。
- **切り替えに共有Appを含める:** 借用中も元と借りたタイル領域の後ろに、共有のフローティング・そのままウインドウが並びます。既定でオンの設定を無効にすれば、共有Appを除いた小さな一覧にできます。
- **Appごとの手前表示をトラブルシュート:** 新しいガイドで、フローティング操作部のあるAppを登録する場面、ブラウザのピクチャインピクチャが自動でタイル対象外になる理由、切り替え後も表示するために登録が必要な条件を説明します。

<a id="fixes-1"></a>
### 修正
- **ブラウザのPiPを配置から除外:** ChromeとDiaのピクチャインピクチャをWindowServerのレイヤーで識別し、BSPタイルに含めません。情報取得に失敗しても有効な通常ウインドウは保持します。
- **手動調整した分割比率を保持:** 論理的なタイル構成が同じなら、フォーカス同期や表示面の交換で50:50へ戻しません。実際の追加・削除には設定に従って自動均等配置を適用します。
- **ポインタのあるディスプレイで切り替え:** 前後のワークスペースやApp・ウインドウの切り替えは、古いキーボードフォーカスではなくポインタのディスプレイを使います。Option-Tabを押している間は開始したディスプレイを保持し、他の画面のタイル外ウインドウを除外して、遅れて届くフォーカス結果で移動しないようにしました。
- **変更した画面に正しく通知:** 表示中のチェーンが実際に結果を生んだ場合だけチェーン名を表示します。フォーカス移動と借用の返却は同じ2行の通知を使え、各通知とフックのデータは変更先の画面を指します。未選択のワークスペースアイコンもアクセント色を保ちます。

<a id="compatibility-1"></a>
### 互換性
- **既存設定のままアップグレード:** 表示、切り替え、通知、ワークスペースチェーンの新しい項目には互換性のある既定値があります。Tatami 1.12へ戻す前に `config.toml` をバックアップし、イベントが `hud` のフックを削除してください。1.12はこのイベントに対応せず、次の保存時に1.13専用のチェーンや設定項目を保持しません。

<a id="1120-2026-08-31"></a>
## 1.12.0 (2026-08-31)

<a id="new-2"></a>
### 新機能
- **分野別CLIでTatamiを自動化:** 同梱の `tatami` は、プロファイル、ワークスペース、ウインドウ、ディスプレイ、配置、Appのサブコマンドとフック確認を提供します。名前やUUIDで選択でき、対応する操作では非アクティブなプロファイルも指定できます。スクリプト向けの安定したJSON形式に対応し、トラックパッドの全38操作を利用できます。プロファイルとワークスペースの有効化以外は、キーやジェスチャーと共通の処理を使います。有効化は完了を待って戻り、旧コマンドも互換エイリアスとして残ります。
- **ライフサイクルフックでプログラムを実行:** Tatamiの起動、プロファイル変更、画面へのワークスペース表示時に実行できます。設定で追加・テストするか `config.toml` に記述します。バージョン付きJSONと環境変数を渡し、argv、作業ディレクトリ、環境、制限時間を指定できます。失敗は問題一覧に表示し、切り替えを妨げません。

<a id="improvements-2"></a>
### 改善
- **複製前に内容を確認:** プロファイルとワークスペースのメニューで名前を変更でき、複製にも「コピー元」と同じ選択式プレビューを使います。ワークスペース、App、設定、保存済み配置を個別に選べます。複製したプロファイルには切り替えキーと自動有効化ルールを含めず、同じプロファイル内の複製ワークスペースでは即座に競合するキーを除きます。
- **自動化変更をトランザクション化:** CLIの変更と確認済みの複製は、保存前に現在の設定を照合します。複製を公開する前に配置を準備し、設定を確定できなければ後片付けします。
- **コマンドの案内をすぐ確認:** 設定から同梱のCLIガイドを開くか、pangmo5.dev/Tatamiで `docs/CLI.md` から生成された案内を読めます。選択方法、JSONの規約、フックの動作、終了ステータス、スクリプト例を説明します。
- **どの幅でもショートカット競合を確認:** 記録コントロールの幅に関係なく同じ小さな警告を表示し、競合する操作の全文をポップオーバーとVoiceOverで確認できます。

<a id="fixes-2"></a>
### 修正
- **プロファイル境界を守るキー:** 別々のプロファイルで同じ代表キーや明示的なショートカットを再利用しても、誤って競合と判断しません。グローバルキーは引き続き全プロファイルと照合します。
- **コピー・複製時のキー競合を防止:** プレビューで競合する選択を示し、保存前に現在の設定を再検証します。競合があれば一部だけを適用せず、変更全体を拒否します。

<a id="1113-2026-08-07"></a>
## 1.11.3 (2026-08-07)

<a id="new-3"></a>
### 新機能
- **Appからの切り替えにもポインタが追従:** ポインタ追従を有効にすると、Dock、Spotlight、App切り替えから開いた際、実際に手前へ出たウインドウへ移動します。同じAppのウインドウが複数あっても、フォーカス先が明確になります。

<a id="improvements-4"></a>
### 改善
- **最近のワークスペースを画面全体で共有:** 新規インストールでは、直前のワークスペースを画面ごとではなくデスクトップ全体で扱います。既存の設定は変更しません。
- **配置変更にポインタも追従:** 分割方向の変更や全画面拡大の切り替えで、フォーカス中のウインドウと一緒にポインタを移動します。ウインドウが離れた古いタイルに残りません。

<a id="fixes-4"></a>
### 修正
- **動的ワークスペースが再びポインタに追従:** 一度表示すると最後の画面に固定される問題を修正しました。有効化するとポインタのあるディスプレイへ移動し、すでにそこにある場合は現在の借用構成を保ちます。
- **複数画面でロック解除後も正しく復元:** ロック中にmacOSが画面を外して追加する中間状態を逐次処理し、割り当てが壊れたり、画面数ルールでプロファイルが変わったまま保存されたりしていました。構成が落ち着いてから反映し、一瞬消えただけなら何も変えず、実際の取り外しは一度だけ処理します。
- **ドラッグを離した場所にポインタを保持:** Appが戻したフレームの修復を追従すべき配置変更と判断し、ドロップ直後にポインタが飛ぶことがありました。ポインタ起因の配置では再移動せず、借用中も同じ動作になります。
- **呼び出した借用領域へ必ずフォーカス:** 無関係な配置書き込みが借用処理を置き換えると、一時領域は見えてもフォーカスとポインタが元に残る問題を修正しました。
- **元の領域を移すと借用を返却:** 借用中の元のワークスペースを別画面へ移した際、再描画まで借りたウインドウが前の画面に残る問題を修正しました。
- **ウインドウのないワークスペースにも切り替え:** すべてのウインドウを閉じたワークスペースで、Appの有効化、非表示処理、操作フィードバックが実行されない問題を修正しました。
- **空いた画面の補充でフォーカスを奪わない:** 動的領域が移った後に別の領域で画面を補っても、利用者が移動した先からキーボードフォーカスやポインタを引き戻しません。
- **更新確認が1クリックで反応:** メニューバーから開くと別のAppの後ろへ出て、2回押すまで動かないように見えた問題を修正しました。
- **切り替え一覧の影を切らない:** 影を含めてパネルの大きさを決め、どの幅でも影全体を表示します。

<a id="1110-2026-07-31"></a>
## 1.11.0 (2026-07-31)

<a id="new-4"></a>
### 新機能
- **各画面で最後のワークスペースを再開:** 再起動後に最後の有効なプロファイル、画面ごとの履歴、全体の使用順を復元します。手動選択は維持し、条件付きプロファイルはルールが一致する場合だけ戻します。一致しなければ接続画面に最適なプロファイルを選びます。

<a id="improvements-5"></a>
### 改善
- **ウインドウ追跡の応答を改善:** ID、機能、位置、フォーカス、ミラー、印がキャッシュ優先の集約更新を共有し、同期AX処理を繰り返しません。Appごとの順序を保ちつつ高負荷のAppが他を止めないようにし、置き換わった検索やフォーカス要求は古い結果を反映できません。
- **わかりやすく正確な切り替え:** 各Appアイコンにフォーカス、借用、共有、常に手前、全画面の状態を表示します。ホバーで実際の選択も変わるので、同じAppに複数のウインドウがあってもReturnや修飾キーを離す操作で強調中のものを確定できます。よりコンパクトになり、「視差効果を減らす」にも対応します。
- **配置設定に従う均等配置:** 均等配置コマンドが自動均等配置で指定した軸を使います。自動設定がオフの場合は、不均等な構造の比率だけを揃えず、標準のBSPツリーを再構築します。

<a id="fixes-7"></a>
### 修正
- **遅れて開く・再表示されるウインドウを安定化:** WindowServerの表示変更に即応し、IDを忘れずに隠れた表示面を取り除きます。再表示されたAppが後から古いフレームを戻してもタイルへ合わせ続けます。遅いAppの最初のウインドウも、監視の準備ができ次第、意図したフォーカス、全画面の位置、フレームを復元します。
- **借用の完了とフォーカスを安定化:** 起動の遅いAppの最初のウインドウも、現れたらすぐ配置してフォーカスします。処理中は元のフォーカスと印を保持し、全体の有効化前に古い印を消します。別の画面や、すでに表示中の元の領域へフォーカスを戻しても借用構成を保ちます。
- **スリープ・復帰中も配置を保持:** スリープ時にWindowServerが表示を解体してもBSPツリーを消しません。復帰後、生きているウインドウを再接続し、再作成された表示面を置き換えて完成した配置として戻します。途中の半端な状態は保存しません。
- **最後のプロファイルを安全に復元:** 手動で選んだプロファイルが有効なら、再起動しても先頭のプロファイルに戻りません。ディスプレイ条件が一致しなくなったプロファイルも復元しません。
- **増減ボタンのクリックを毎回保存:** 間隔、時間、マーカーサイズ、ジェスチャーしきい値、借用比率をmacOSのStepper更新ごとに保存します。通常のクリックでは届かない場合がある編集終了コールバックには依存しません。
- **ガイド付き設定の全画面動作を統一:** 仮想配置エディタが全画面ウインドウを集合として管理し、練習用ワークスペースで複数の全画面ウインドウを使えます。保存済みや旧形式の下書きを再開しても状態を保ちます。

## 1.10.0 (2026-07-27)

<a id="new-5"></a>
### 新機能
- **5つの表示言語:** 設定、ガイド付き設定、メニューバー、操作フィードバック、エラー、確認画面が英語・韓国語・日本語・簡体字中国語・繁体字中国語に対応しました。macOSでTatamiに指定したAppの言語に従います。

<a id="improvements-6"></a>
### 改善

<a id="010-2026-05-27"></a>
## 0.1.0 (2026-05-27)

初の公開版です。yabai方式のタイル表示を備えたmacOSワークスペース管理ツールです。Appを仮想領域にまとめ、キーやトラックパッドのスワイプで切り替え、自動配置できます。SIPの変更やシェルスクリプトは不要です。

<a id="tiling-yabai-style-bsp"></a>
### タイル表示（yabai方式のBSP）
- **BSPで自動配置:** dwindle（らせん状）の二分空間分割でウインドウを自動配置します。
- **方向別のウインドウ操作:** vim風の `h` `j` `k` `l` でフォーカス、交換、サイズ変更ができます。
- **ワークスペースいっぱいに拡大:** ウインドウをワークスペース全体へ拡大し、分割方向を切り替えられます。
- **高度な配置操作:** 回転、反転、均等配置、ドラッグでの入れ替え、サイズ変更の即時同期に対応します。
- **間隔を設定:** 内側と外側の間隔を調整できます。

<a id="workspaces"></a>
### ワークスペース
- **ワークスペースへのApp割り当て:** 領域ごとにAppを指定し、キー、スワイプ、最近の領域で切り替えます。
- **柔軟なワークスペース切り替え:** 端から先頭へ戻る、空の領域を飛ばす、Appフォーカスに追従する設定を使えます。
- **Appの自動起動:** ワークスペースの有効化時に、割り当てたAppを自動で開きます。
- **複数画面への配置:** ワークスペースを画面に固定するか、Appへ動的に追従させられます。
- **フローティングAppをタイル対象外に:** フローティングAppはタイル表示しません。

<a id="focus--interface"></a>
### フォーカスとインターフェイス
- **マウスによるフォーカス制御:** マウスにフォーカスを追従させる、フォーカスにポインタを追従させる、必要に応じてポインタを隠す操作に対応します。
- **メニューバーに現在の領域を表示:** アクティブなワークスペースのアイコンと名前を表示します。
- **切り替えの操作フィードバック:** ワークスペースを切り替えると、領域ごとのSF Symbolアイコン付きで表示します。
- **設定と自動化:** skhd形式のショートカット、通常のTOML設定、スクリプト用CLIを利用できます。
