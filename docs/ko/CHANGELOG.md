# 변경 기록

Tatami의 주요 변경 사항이에요. 이 파일은 웹사이트와 GitHub Releases에 표시하는 릴리즈 노트의 기준이며, 배포 과정에서 설치·업데이트 안내를 덧붙여요. Sparkle 업데이트 창은 같은 마이너 버전의 모든 패치 내역을 모아 보여주므로 각 섹션에는 해당 버전의 변경만 적어요.

<a id="1140-2026-09-09"></a>
## 1.14.0 (2026-09-09)

작업 공간 전환과 창 조작의 반응성을 높이고, 저장된 설정에 영향을 주는 변경은 적용 전에 확인할 수 있어요.

<a id="new"></a>
### 새로운 기능
- **변경 전에 확인하기:** 앱 소속·배치 변경, 삭제, 설정 덮어쓰기, 가이드 설정 교체를 적용하기 전에 검토할 수 있어요. 확인은 동작별로 독립적으로 켜져 있어요. ‘다시 보지 않기’는 실행을 확정한 동작만 끄고, 취소하면 설정을 유지해요. 앱 소속·배치 변경은 확인 후 같은 HUD에 결과를 보여줘요.

<a id="improvements"></a>
### 개선 사항
- **작업 공간 전환과 입력 반응성 높이기:** 설정·배치 저장을 입력 처리에 민감한 경로 밖에서 순서대로 실행하고, 중복 포인터 업데이트를 합쳐요. 창이나 포커스 대상이 바뀌면 이전 작업의 결과를 버려요.
- **앱 동작을 한곳에서 조정하기:** 앱 행에서 자동 열기와 배치 방식을 바로 조정하고 옆 메뉴에서 제거할 수 있어요. 작업 공간 앱과 공유 앱에서 같은 조작을 사용하며, 체인이 없는 작업 공간 행도 중앙 정렬을 유지해요.
- **목적별로 설정 찾기:** 사이드바에서 일반, 타일링, 작업 공간, 작업 공간 키, 포커스와 마우스, 제스처, 모양, 훅을 나눠 볼 수 있어요. 확인 설정도 대상 동작별로 묶었어요.
- **5개 언어로 사용법 읽고 보기:** 앱 내 문서는 선택한 언어로 표시되며 제목 이동, 표, 링크가 정상 동작해요. 웹사이트에는 전체 작업 흐름과 기능별 데모 모음을 추가했고, 기본 재생 컨트롤, 키보드 탐색, 관련 설정 링크를 제공해요.

<a id="fixes"></a>
### 수정 사항
- **항상 위 창에 첫 클릭·드래그 전달하기:** 창 활성화와 미러 전환 중에도 첫 마우스 입력을 유지해요. 키보드 포커스를 옮기지 않고 뒤쪽 창을 스크롤할 수 있으며, 마우스를 올렸을 때의 동작은 FFM 설정을 따라요.
- **창을 잠시 찾을 수 없어도 배치 보존하기:** 배치 읽기가 실패하거나 불완전하다고 해서 저장된 위치를 빈 배치로 덮어쓰지 않아요. 작업 공간 복원은 필요한 창을 확인할 수 있을 때까지 유효한 배치 정보를 유지해요.
- **변경 없는 작업 공간 복사 건너뛰기:** 설정이 같은 복사 원본은 ‘차이 없음’으로 표시되며 선택할 수 없어요. 검토 화면을 열기 직전에 원본과 대상을 다시 확인하므로, 오래 열린 메뉴가 빈 복사 화면을 띄우지 않아요.

<a id="compatibility"></a>
### 호환성
- **자동화의 확인 설정 점검하기:** 기존 구성은 새 동작별 확인이 모두 켜진 상태로 불러와요. 앱 소속·배치를 저장하는 CLI 명령에도 이 확인을 적용해요. 무인 스크립트에서는 설정 → 일반 → 변경 전 확인 또는 `[settings.confirmations]`에서 관련 옵션을 지정하세요. 다운그레이드 전에 `config.toml`을 백업하세요. 이전 버전은 저장할 때 새 확인 옵션을 보존하지 않아요.

<a id="1130-2026-09-03"></a>
## 1.13.0 (2026-09-03)

<a id="new-1"></a>
### 새로운 기능
- **디스플레이 전체의 작업 공간 묶음 복원:** 프로필 설정에서 순서 있는 체인을 만들고 멤버 하나를 전환하면 현재 화면 구성에 맞는 나머지도 복원해요. 선택한 공간은 포커스를 유지하고, 연결된 고정 멤버는 지정 화면을 차지해요. 체인 동적 멤버는 우선순위대로 다음 빈 화면을 사용하고 남은 화면은 기존 규칙으로 채워요. 사이드바에 관계를 표시하며 변경된 각 디스플레이에 결과를 알려줘요.
- **지속적인 플로팅 컨트롤 유지:** 기존 앱 선택기로 Notion 같은 앱을 등록할 수 있어요. 등록한 앱의 높은 레이어 컨트롤이 화면에 보이는 동안 앱을 숨기지 않아 작업 공간을 전환해도 유지해요. 일반 창은 포커스·타일링·순환·드래그·소속 변경 대상에서 제외하지만 Mission Control에는 보일 수 있어요.
- **다른 화면 요소로 동작 알림 전달:** 새 `hud` 훅으로 작은 화면 알림의 번역된 제목·기호·부제·완전 표시 시간·위치·크기·결정된 디스플레이를 전달해요. SketchyBar 같은 연동 도구가 로그를 해석하지 않고 같은 정보를 표시할 수 있고, 훅 실패 알림은 재귀적으로 다시 전달하지 않아요.

<a id="improvements-1"></a>
### 개선 사항
- **작은 화면 알림의 위치·크기 설정:** 해당 디스플레이의 가장자리·모서리·가운데와 작게·기본·크게를 선택할 수 있어요. 스프링 동작으로 나타나고 사라지며, 설정한 시간은 완전히 보이는 구간만 계산해요.
- **앱·창 전환에 공용 앱 포함:** 빌려오기 중에도 원래 공간과 빌려온 타일 영역 뒤에 공용 항상 위·그대로 두기 창을 보여줘요. 기본으로 켜진 설정을 끄면 더 좁은 목록에서 공용 앱을 제외할 수 있어요.
- **앱별 항상 위 동작 문제 해결:** 새 안내에서 플로팅 컨트롤 앱을 언제 등록해야 하는지, 브라우저 화면 속 화면이 왜 타일링에서 자동 제외되는지, 작업 공간을 바꿔도 유지하려면 언제 등록이 필요한지 설명해요.

<a id="fixes-1"></a>
### 수정 사항
- **브라우저 화면 속 화면 타일링 제외:** Chrome·Dia의 PiP 창을 WindowServer 레이어로 구분해 BSP 타일에 넣지 않아요. 메타데이터 조회가 실패해도 정상적인 일반 창은 계속 유지해요.
- **직접 조절한 분할 비율 유지:** 타일의 논리적 구성원이 같다면 포커스 동기화나 창 표면 교체가 비율을 50:50으로 초기화하지 않아요. 실제 창 추가·제거에는 설정에 따라 자동 균등 배치를 적용해요.
- **포인터가 있는 디스플레이에서 전환:** 이전·다음 작업 공간과 앱·창 전환은 오래된 키보드 포커스 대신 포인터의 디스플레이를 사용해요. Option-Tab을 누르는 동안 처음 디스플레이를 유지하고, 다른 디스플레이의 비타일 창을 제외하며, 늦게 끝난 포커스 조회 때문에 이동하지 않아요.
- **변경된 디스플레이에 정확히 알림:** 보이는 체인이 실제 결과를 만들었을 때만 체인을 표시해요. 포커스 이동과 빌려오기 반환은 같은 두 줄 알림을 쓸 수 있고, 각 알림·훅 데이터는 변경된 디스플레이를 대상으로 해요. 선택하지 않은 작업 공간 아이콘도 강조색을 유지해요.

<a id="compatibility-1"></a>
### 호환성
- **기존 설정 그대로 업그레이드:** 표시·전환기·화면 알림·작업 공간 체인의 새 필드는 이전 설정과 호환되는 기본값을 제공해요. Tatami 1.12로 낮추기 전에는 `config.toml`을 백업하고 이벤트가 `hud`인 훅을 제거해 주세요. 그 버전은 해당 이벤트를 모르며, 다음 저장 때 1.13 전용 체인·설정 필드를 보존하지 않아요.

<a id="1120-2026-08-31"></a>
## 1.12.0 (2026-08-31)

<a id="new-2"></a>
### 새로운 기능
- **분야별 CLI로 Tatami 자동화:** 번들 `tatami` 명령은 프로필·작업 공간·창·디스플레이·레이아웃·앱 하위 명령과 훅 조회로 구성돼요. 이름이나 UUID로 선택하고, 지원하는 명령에서는 비활성 프로필도 대상으로 삼으며, 스크립트용 고정 JSON 형식을 받을 수 있어요. 트랙패드 제스처의 실행 동작 38개를 모두 제공해요. 프로필·작업 공간 활성화 외의 제스처 대응 명령은 단축키·제스처와 같은 디스패처를 사용해요. 활성화 명령은 처리가 끝난 뒤 반환하고, 기존 단일 명령도 호환 별칭으로 유지해요.
- **수명 주기 훅으로 프로그램 실행:** Tatami 시작·활성 프로필 변경·디스플레이의 작업 공간 표시 시 프로그램을 실행할 수 있어요. 설정에서 추가·테스트하거나 `config.toml`에 작성해요. 버전이 있는 JSON과 편의 환경 변수를 전달하며 argv·작업 폴더·환경·제한 시간을 명시할 수 있어요. 실패는 문제 목록에 표시하고 프로필·작업 공간 전환을 막지 않아요.

<a id="improvements-2"></a>
### 개선 사항
- **적용 전에 복제 내용 검토:** 프로필·작업 공간 메뉴에서 이름을 바꿀 수 있고, 복제할 때도 가져오기와 같은 선택형 미리보기를 사용해요. 작업 공간·앱·설정·저장된 레이아웃을 개별 선택할 수 있어요. 프로필 복제본에는 전환 단축키와 자동 활성화 규칙을, 같은 프로필의 작업 공간 복제본에는 즉시 충돌할 단축키를 넣지 않아요.
- **자동화 변경의 트랜잭션 보장:** CLI 수정과 검토한 복제는 저장 전에 현재 설정을 확인해요. 복제본을 공개하기 전에 레이아웃을 준비하고, 설정을 확정할 수 없으면 정리해요.
- **앱 가까이에서 명령어 안내 확인:** 설정에서 번들 CLI 안내를 열거나 pangmo5.dev/Tatami에서 `docs/CLI.md`으로 만든 안내를 읽을 수 있어요. 선택자, JSON 규약, 훅 동작, 종료 상태, 스크립트 예제를 다뤄요.
- **어떤 너비에서도 단축키 충돌 확인:** 기록기 크기와 관계없이 같은 작은 경고를 보여주고, 충돌한 전체 동작은 팝오버와 VoiceOver로 확인할 수 있어요.

<a id="fixes-2"></a>
### 수정 사항
- **프로필 경계를 지키는 작업 공간 단축키:** 서로 다른 프로필에서 같은 대표 키나 명시적 단축키를 재사용해도 잘못된 충돌로 보지 않아요. 전역 단축키는 모든 프로필과 계속 비교해요.
- **복사·복제로 단축키 충돌 방지:** 미리보기에서 충돌하는 선택을 알려주고 저장 전에 현재 설정을 다시 검사해요. 실제 충돌이 있으면 일부만 복사하지 않고 전체 변경을 거절해요.

<a id="1113-2026-08-07"></a>
## 1.11.3 (2026-08-07)

<a id="new-3"></a>
### 새로운 기능
- **앱에서 시작한 전환에도 포인터 이동:** 포인터가 포커스를 따라가도록 설정하면 Dock·Spotlight·앱 전환기로 앱을 열 때 실제로 앞으로 온 창으로 포인터를 옮겨요. 같은 앱의 창이 여러 개여도 어느 창이 포커스를 받았는지 분명해요.

<a id="improvements-4"></a>
### 개선 사항
- **최근 작업 공간을 디스플레이 전체에서 기억:** 새 설치에서는 최근에 머문 작업 공간을 모니터별이 아닌 전체 데스크톱 기준으로 다뤄요. 기존 설정은 유지해요.
- **레이아웃 명령을 따라 포인터 이동:** 분할 방향을 바꾸거나 전체 화면 확대를 켜고 끄면 포커스한 창과 함께 포인터를 옮겨요. 창이 떠난 예전 타일에 포인터가 남지 않아요.

<a id="fixes-4"></a>
### 수정 사항
- **동적 작업 공간이 다시 포인터를 따라가요:** 한 번 표시한 뒤 마지막 모니터에 고정되던 문제를 수정했어요. 동적 작업 공간을 활성화하면 포인터가 있는 디스플레이로 가져와요. 이미 그 디스플레이에 있다면 진행 중인 빌려오기 구성을 유지해요.

- **공용 앱 편집기:** 작업 공간 사이드바의 전용 공간에서 공용 앱을 추가·제거하고 항상 위를 켜거나 끌 수 있어요.
- **시스템 설정 방식의 사이드바:** 일반·타일링·포커스와 마우스·작업 공간·단축키·모양으로 나누고, 권한에 화면 기록 항목을 추가했어요.
- **공용 앱 단축키:** `toggleSharedFloating`으로 포커스 앱을 모든 공간에 띄워요. 필요하면 공용 앱에 항상 위로 추가하고, 끄면 공용 타일 앱으로 바꿔요. `toggleAppInSharedApps`은 공용 앱에서 추가·제거해요.
- **동작별 화면 알림:** 항상 위·앱 소속·타일링 일시 정지·전체 화면 확대·균등 배치를 짧게 알려줘요. **설정 → 모양 → 오버레이**에서 각각 켜고 끄거나 전체 스위치와 시간을 설정할 수 있어요. 항상 위를 해제해도 작업 공간·공용 앱에 남는 앱에는 완전히 제거하는 단축키를 이어서 안내해요.

- **메뉴 막대에 현재 작업 공간 표시:** 활성 작업 공간의 아이콘과 이름을 메뉴 막대에 보여줘요.
- **작업 공간 전환 알림:** 전환할 때 공간별 SF Symbol 아이콘과 화면 알림을 보여줘요.
- **설정과 자동화:** skhd 방식 단축키 문법, 일반 TOML 설정, 스크립트용 CLI를 사용할 수 있어요.
