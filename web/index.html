Window tiling

Tiled automatically, controlled precisely.

A binary-space-partitioning engine tiles each workspace's windows as you open them. It is fully native and needs no shell scripting.

▦

Automatic BSP

Tatami makes room for new windows by splitting a tile, with configurable inner and outer gaps. Each workspace keeps its layout and ratios across relaunches and system sleep.

⌨️

Control it from the keyboard

Move focus with h j k l, swap windows with the arrow keys, and grow or shrink the focused split with = and -. Hold the window-switch shortcut for a compact, state-aware switcher scoped to the display under the pointer.

🖱️

Drag to rearrange

Drag a window onto another and a live preview shows the swap or insertion before you drop. Resize an edge by hand and the layout remembers the ratio.

⊞

Docked & tiled

Pull a workspace to the top, bottom, left, or right. The two blocks tile beside each other with separate BSP layouts, and windows stay on their own side.

↔️

Changes stay in sync

The borrowed block is the real workspace, so changes stay with it. Directional focus and MFF cross the seam, while host and borrowed tiled windows share one switching order. Activate it to switch over fully, or borrow it again to return it.

⌨️

A key and a direction

Hold the borrow modifier with a workspace's key, then press a direction (h j k l or arrows). You can also set a default edge and size. Scratchpad workspaces are borrow-only.

Always on Top

Keep important windows above the layout.

Some windows should remain visible, including a video call, a simulator, or a music player. Choose Always on Top and Tatami keeps them above the layout.

🪟

Per-workspace or shared

Keep an app on top in one workspace or add it to Shared Apps to keep it on top everywhere. Use one setting in the app or one shortcut anywhere.

🎯

The real window, on demand

Reach for an always-on-top window and Tatami hands you the actual window. Type, drag, and resize as usual. Focused windows stack by recency.

🛡️

System protection stays on

Tatami uses ScreenCaptureKit mirrors with Screen Recording permission instead of changing protected system settings. System Integrity Protection stays on.
