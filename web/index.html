Virtual workspaces

A space for every task.

Group your apps into workspaces and jump between them in a keystroke. Each one brings exactly the windows you assigned it, on the display you want.

🗂️

Switch your way

Use hotkeys or bind every three- and four-finger swipe direction to a shortcut action. Recent navigation can stay on one display or follow a global history.

🖥️

Per-display workspaces

Pin a workspace to a monitor or let a dynamic workspace follow the pointer. Every display keeps its own active and recent workspace across relaunches, and either navigation mode can stay local or span all displays.

🚀

Auto-open & shared apps

Assigned apps launch when their workspace activates and reopen on re-entry. Shared apps join every workspace.

Profiles

Switch your whole setup at once.

Group workspaces into profiles, such as one for the laptop and one for the desk, then switch the entire set with a keystroke. Every display re-tiles for the new profile.

🗄️

A setup for every situation

Each profile has its own workspaces, app assignments, and shortcuts. Switch by hotkey or from the menu bar, then return to the setup that fits your connected displays after relaunch.

🔌

Auto-switch by display

Activate a profile automatically by monitor count or by specific displays being connected or unplugged. Overlapping rules get flagged.

📋

Start from an existing setup

Copy selected workspaces and settings from another profile, or duplicate one as a starting point. Review what will be brought over before applying.

Workspace composition

Two workspaces, side by side.

Need one workspace's window while you work in another? Borrow it beside the current one, docked to a screen edge, with each block keeping its own layout.

⊞

Docked & tiled

Pull a workspace to the top, bottom, left, or right. The two blocks tile beside each other with separate BSP layouts, and windows stay on their own side.

↔️

Changes stay in sync

The borrowed block is the real workspace, so changes stay with it. Directional focus and MFF cross the seam, while host and borrowed tiled windows share one switching order. Activate it to switch over fully, or borrow it again to return it.

⌨️

A key and a direction

Hold the borrow modifier with a workspace's key, then press a direction (h j k l or arrows). You can also set a default edge and size. Scratchpad workspaces are borrow-only.

Window tiling

Tiled automatically, controlled precisely.

A binary-space-partitioning engine tiles each workspace's windows as you open them. It is fully native and needs no shell scripting.

▦

Automatic BSP

New windows split the shallowest tile and drop into place, with configurable inner and outer gaps. Each workspace keeps its tree and ratios across relaunches and system sleep.

⌨️

Control it from the keyboard

Move focus with h j k l, swap windows with the arrow keys, and grow or shrink the focused split with = and -. Hold the window-switch shortcut for a compact, state-aware switcher and choose the exact target with the keyboard or pointer.

🖱️

Drag to rearrange

Drag a window onto another and a live preview shows the swap or insertion before you drop. Resize an edge by hand and the layout remembers the ratio.

Always on Top

Keep important windows above the layout.

Some windows should remain visible, including a video call, a simulator, or a music player. Choose Always on Top and Tatami keeps them above the layout.

🪟

Per-workspace or shared

Keep an app on top in one workspace or add it to Shared Apps to keep it on top everywhere. Use one setting in the app or one shortcut anywhere.

🎯

The real window, on demand

Reach for an always-on-top window and Tatami hands you the actual window. Type, drag, and resize as usual. Focused windows stack by recency.

🛡️

System protection stays on

Tatami uses ScreenCaptureKit mirrors with Screen Recording permission instead of changing protected system settings. System Integrity Protection stays on.

Guided Setup

Learn Tatami by using it.

First launch turns this Mac's app metadata and displays into a draft, then teaches every major feature in order on a safe virtual display. Nothing moves and no configuration is written until you apply.

🧭

Built around your setup

Shape repeatable workspaces, assign the apps you already use, and carry those choices through switching, tiling, Borrow, window handling, focus, and window-switching lessons.

🖥️

Practice on a virtual display

Use the real shortcuts and trackpad gestures you configured. Each later lesson keeps the earlier commands active, without touching your real windows.

✨

Bring your preferred AI

Review a workspace proposal from ChatGPT, Claude, Gemini, another AI, or on-device Apple Intelligence on supported Macs. Tatami shares app metadata and display geometry, never screen contents.

For power users

Optional automation for custom workflows.

Use Tatami's CLI in scripts, or run a hook when Tatami launches, changes profile, or makes a workspace visible.

Command line Run workspace and window commands or request JSON. Lifecycle hooks Run a program when Tatami launches, profiles change, or workspaces appear.
