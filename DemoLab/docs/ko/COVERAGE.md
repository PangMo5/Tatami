# 데모 범위와 검증

공개 목록에는 전체 작업 흐름 1개와 개별 기능 데모 26개, 총 27개 장면이 있어요. 지원 언어마다 앱 UI, 데모 콘텐츠, 입력, 자막, 촬영 검증 조건이 따로 있어요. 언어, 촬영한 동작, 촬영 품질로 검증된 원본을 골라 각각 내보내요.

## 촬영 범위

| --- | --- | --- |
|작업 공간|3|직접·최근·순서대로 전환, 자동 열기·다시 열기, 앱 배정 이동.|

종합 영상은 디자인·색상 선택, PNG 저장, 글쓰기, 검토·승인, 빌려오기, 공용 상태, CLI, 화면별 프로필을 한 작업으로 이어줘요. Canvas, Editor, Docs, Review, Chat, Notes, Terminal, Monitor는 조작할 수 있는 로컬 앱이에요. 창 관리는 Tatami가 하고 훅·CLI 결과는 실제 프로세스가 만들어요.

<a id="evidence-and-acceptance"></a>
## 검증 자료와 통과 기준

검증된 촬영본은 실제 동작·상태·배치 검증을 통과하고, 현재 언어별 촬영 동작과 타이밍이 일치하며, 프레임 손실이 1% 미만이어야 해요. 자막만 수정하면 원본 장면 해시를 보관하고 수정본 해시를 추가해요. 내보낼 때 MP4 전체, H.264/yuv420p, 길이·용량 제한, 첫 자막 시점, 영상과 타임라인의 공통 시계를 확인해요.

출력의 `evidence/`에 고정 장면 JSON, 촬영 정보, 자막, 시간, 검수 이미지, OCR와 브라우저 결과를 남겨요. 각 배치의 숫자와 검수 상태는 그 보고서로 확인하고 이전 보고서를 새 언어·테이크의 증거로 쓰지 마세요.

영상 색상은 웹의 다크 팔레트, 글꼴은 촬영 언어를 따라요. 영상과 포스터 URL에 출력 해시를 넣어 예전 버전과 섞이지 않게 해요.

<a id="boundaries-and-an-unresolved-reproduction"></a>
## 검증 경계와 미해결 재현

- **macOS 전체화면 복귀:** 원래 검사에서 전체화면을 끝낸 뒤 Canvas와 Docs가 모두 작업 공간 전체 크기로 남았어요. 원인은 아직 분리하지 못했어요. `scenes/native-fullscreen.json`과 실패한 `recordings/v4-edge1/fullscreen*`에 재현을 보관하고 공개용에서 제외했어요. `fullscreen` 영상은 통과한 Tatami 자체 확대·복귀예요.
- **실제 제스처:** 안내의 미리보기 버튼과 실제 키보드를 사용해요. VM만으로 물리 세 손가락·네 손가락 인식을 입증하지 않아요.
- **AI:** 표시해둔 로컬 예시이며 외부 AI를 호출하지 않아요. 촬영 뒤 실제 TOML에 원래 공간 이름이 남아 있는지 확인했어요. 예시는 초안에만 반영됐어요.
- **여러 화면:** 게스트의 CoreGraphics 화면 두 개를 실제로 열거·관리·개별 녹화하고 시간으로 맞췄어요. 물리 독·혼합 DPI·HDR·케이블 동작은 입증하지 않아요. 비공개 도구는 Demo Lab에만 있고 OS가 바뀌면 다시 검증해야 해요.
- **범위:** 위 주요 동작을 다루며 모든 설정·언어·업데이트 과정·하드웨어 조합을 완전히 검사한 것은 아니에요.

<a id="capture-defects-corrected"></a>
## 고친 촬영 결함

화살표 이벤트의 숫자패드·기능키 정보를 유지하도록 고쳤어요. 같은 단축키로 비교해서 빠진 정보를 확인했으며 [Apple 문서](https://developer.apple.com/documentation/appkit/nsevent/modifierflags-swift.struct/numericpad)에도 설명되어 있어요. 컨트롤은 보이도록 스크롤한 뒤 누르고 가려진 창은 실제 전환기로 골라요. 동기화·가져오기는 새 아카이브를 쓰고 양쪽 해시를 확인해요.

macOS VM에 두 번째 화면을 만들 수 없다는 예전 설명은 잘못됐어요. 실제 사용한 API는 [DeskPad 인터페이스](https://github.com/Stengo/DeskPad/blob/main/DeskPad/CGVirtualDisplayPrivate.h), 구성과 재현은 [MULTI-DISPLAY.md](MULTI-DISPLAY.md)에서 확인해요.
