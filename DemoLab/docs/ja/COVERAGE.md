# デモの範囲と検証

公開一覧は、一連の作業を示す 1 本と個別機能のデモ 26 本、計 27 シーンです。各言語に専用のアプリ表示、デモ内容、入力、字幕、撮影時の検証条件があります。言語、撮影した操作、画質をもとにテイクを選び、個別に書き出します。

<a id="captured-coverage"></a>
## 録画の範囲

|動画集|動画数|示す動作|
| --- | --- | --- |
|ワークスペース|3|直接・直前・順番での切り替え、自動起動・再度開く、アプリの移動。|
|プロファイルと画面|5|プロファイル切り替え、GUI での複製、ワークスペースの選択コピー、2 画面のチェーン、画面間フォーカス、接続・切断に応じた自動切り替え。|
|タイル表示とフォーカス|7|ウインドウの追加・終了、入れ替え、分割方向、サイズ調整・均等配置、ドラッグ、拡大、方向指定フォーカス、MFF/FFM、長押し・短押しの切り替え、ネイティブの配置エディタ。|
|借りる|3|横での会話、内容が残る一時スペース、方向選択、境界を越えるフォーカス、完全な切り替えと返却。|

主動画はデザイン、PNG 保存、執筆、確認・承認、借りる操作、共有状態、CLI、画面別プロファイルをつなぎます。Canvas、Editor、Docs、Review、Chat、Notes、Terminal、Monitor は操作できるローカル例です。窓は Tatami が管理し、結果は実際のプロセスが作ります。

<a id="evidence-and-acceptance"></a>
## 証拠と合格条件

採用するテイクは、実際の操作・状態・配置の検証を通過し、現行の言語別シーンの操作とタイミングに一致し、フレーム欠落率が 1% 未満である必要があります。文面だけの修正では元シーンのハッシュを残し、編集後のハッシュを追加します。書き出し時に MP4 全編、H.264/yuv420p、長さ・容量の上限、冒頭字幕の時刻、映像とタイムラインの共通時計を確認します。

出力の `evidence/` に固定 JSON、録画情報、字幕、時刻、画像、OCR、ブラウザ結果を残します。そのバッチの数や状態は対応する報告で確認し、古い報告を別言語や新テイクに使わないでください。

色は Web の暗色パレット、書体は撮影言語に合わせます。動画とポスターの URL にハッシュを付け、旧版との混在を防ぎます。

<a id="boundaries-and-an-unresolved-reproduction"></a>
## 検証の境界と未解決の再現

- **macOS 全画面からの復帰：** Canvas と Docs が両方とも全体サイズに残りました。原因は未特定で、`scenes/native-fullscreen.json` と失敗した `recordings/v4-edge1/fullscreen*` に再現を保存し公開から外しました。`fullscreen` は合格した Tatami 自身のズームです。
- **実際のジェスチャ：** ガイドのプレビューボタンと実キーを使います。VM から実物の 3 本指・4 本指認識は主張しません。
- **AI：** 明示したローカル例で、外部 AI を呼びません。録画後も実際の TOML に元の名前が残ることを確認し、下書きだけに反映しました。
- **複数画面：** ゲストの二つの CoreGraphics 画面を認識・管理・別録画し、時刻で揃えました。実物のドック、混在 DPI、HDR、ケーブルの証明ではありません。専用ヘルパーは OS ごとに再検証が必要です。
- **範囲：** 上記の主な操作が対象で、全設定、言語、更新経路、ハードウェアの網羅的 QA ではありません。

<a id="capture-defects-corrected"></a>
## 修正した録画の問題

矢印のテンキー・機能キー情報を保持し、同じキーの比較で欠落を特定しました。[Apple の説明](https://developer.apple.com/documentation/appkit/nsevent/modifierflags-swift.struct/numericpad)も参照できます。操作前に表示までスクロールし、隠れた窓は実際の一覧で選びます。転送は新規アーカイブと両側のハッシュを使います。

macOS VM に二画面目を作れないという以前の説明は誤りでした。API は [DeskPad の定義](https://github.com/Stengo/DeskPad/blob/main/DeskPad/CGVirtualDisplayPrivate.h)、構成と再現は [MULTI-DISPLAY.md](MULTI-DISPLAY.md) にあります。
